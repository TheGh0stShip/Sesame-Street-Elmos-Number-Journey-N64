# r4 report: end-to-end rebuild
Both ROMs rebuild to images with the original SHA-1. All 964 + 973 functions are compiled from the v17 sources and linked with a link map derived from the typed data (no instruction words taken from the ROM).
Bytes by source (of 8,388,608): Letter: rebuilt from extracted files 5,725,985; compiled 438,140; generated padding 783,029; generated gzip headers/trailers and header CRCs 242; reproduced total 6,947,396 (82.82%); extracted-verbatim .bin dumps 109,528; exceptions (original bytes placed) 1,331,684 (15.87%). Number: 6,100,415; 444,652; 206,083; 233; total 6,751,383 (80.48%); verbatim 87,970; exceptions 1,549,255 (18.47%).
Exceptions: gzip deflate streams of the 8 level members per game (1,286,968 / 1,505,310 B; zlib at any level, memLevel, strategy or window does not reproduce them; inflated content proven equal); ADPCM frame headers the WAV does not determine (40,289 / 39,371 B); IPL3 (4,032 B each); header fields other than the CRCs (56 B each); stale non-zero bytes in padding rows (339 / 486 B).
Caveats: level images were re-compressed from lvlA's inflated images, not re-assembled from the lvlB-lvlH extractions; some extracted forms carry a few literal bytes (songs hex lines, audio verbatim frame list, sprA tails); packC textures and RSP microcode are read back from .bin dumps.
