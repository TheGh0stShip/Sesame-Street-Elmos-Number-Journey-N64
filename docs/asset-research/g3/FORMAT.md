# g3: level-image rebuild from extracted parts (formats of the tools and outputs)

## Tools
- `tools/rebuild_levels.py GAME OUTDIR [--owners lvlB,lvlC,...]`: builds each of the 8 inflated level images of
  GAME from the owners' extracted files and compares it byte for byte with `lvlA/out/<game>/<name>.bif.bin`.
  Run through job.sh with the lab venv (no numpy/PIL needed). Reads the ROM; writes only under OUTDIR.
  Prerequisite (once per game): lvlB's extractor in extract mode into `OUTDIR/lvlB/<game>`
  (`lvlB/tools/extract_level_gfx.py ROM GAME out/lvlB/GAME`), because lvlB's vertex and model-header forms are new.
- `tools/lprobe.py`: r4's probe, one layer down. The extractor runs in its check direction with:
  - the ROM as a ProbeBytes (space `ROM`);
  - `zlib` replaced (sys.modules, for the run) by a shim. Inflating a ROM slice inside a gzip level member returns a
    ProbeBytes in image space (`<name>.bif`, offsets = image offsets). This also covers raw-deflate after a skipped
    header (lvlF).
  - Every `==`/`!=` of an image slice against plain bytes records (image, offset, rebuilt bytes, equal, last extracted
    file opened). Slice-vs-slice tests are ignored, so no ROM/image byte enters a capture.
  - `builtins.open` is patched for the run: writes outside g3/ go to /dev/null, and `os.makedirs` outside g3/ is a
    no-op. Helper modules (png.py etc.) are covered too.
- Owner runs: lvlB check (on OUTDIR/lvlB/<game>), lvlC check (lvlC/out/<game>/json), lvlD check, r1 check;
  Letter lvlE check + lvlF check; Number lvlG check + lvlH check (the only level owners per game in the ledger).
  Encoder fallback: for ledger rows of lvlG that its check did not re-encode from a decoded file, lvlG's own
  `read_item()` is called on the row's extracted file (its classifier and its MAP.tsv disagree on 3 rows of bump).

## Changes to other agents' tools (originals kept)
- `lvlB/tools/extract_level_gfx.py` (original `extract_level_gfx.py.orig`):
  - Extract also writes `vtx/vtx_<RAM>.txt`: one line per Vtx, `x y z flag s t r g b a`, decimal. This is lossless.
    level.obj was lossy and lvlB had no other vertex form.
  - Extract also writes `mh/mh_<RAM>.json`: the 0x24-byte model record as 9 u32 words, pointers as RAM addresses.
  - Check now reassembles each display list from its macro-text file, not from the in-memory lines, and re-encodes
    textures/TLUTs from the PNG on disk (it no longer rewrites the PNG first). Check also verifies vtx/ and mh/.
- `lvlH/tools/extract_level_rest.py` (pre-edit copy `extract_level_rest.py.pre-g3`; the older `.orig` is
  lvlH's own): check now re-encodes from the written `<off>_<cls>.json`. It used to re-encode the in-memory decode
  of the image.

## Source of a byte
1. A ledger row is painted with its owner's captures, then with any other owner's (`(other-owner)`).
2. `pad` rows are generated as zeros. `elf_comment` rows are generated as repeated `GCC: (GNU) 2.7.2\0\0`; the
   row starts after the first NUL of the first `\0GCC: (GNU) 2.7.2\0` entry. A generated byte is kept when it
   equals the original. Otherwise a capture replaces it, and failing that the byte is an exception.
3. Captures are classified by the extracted file they were re-encoded from:
   - `extracted-verbatim` when that file is a raw dump: a `.bin`, a JSON whose payload is a `hex` string, a text
     file of hex word pairs (lvlE/lvlG texload DLs), or lvlF's display-list word list.
   - `rebuilt-from-extracted` for anything else (PNG, macro text, decoded JSON, vertex text). Pointers stored in
     JSON as addresses or offsets count as rebuilt.
4. An unequal test is painted before the equal ones. That way, a side test (r1 counts zero palette entries with
   `pal[i:i+2] == b'\0\0'`) cannot hide the real test.
5. Anything left is an `exception`. The original byte is placed and the reason is given in `note`.

## LEVELREBUILD_<game>.tsv
Columns: `file start end bytes owner class kind source equal note`. Offsets are inside the inflated image. A ledger
row is split wherever source or equality changes. `source`: rebuilt-from-extracted, rebuilt-from-extracted(other-owner),
extracted-verbatim, extracted-verbatim(other-owner), generated, exception.

## LEVELSUMMARY_<game>.json
- Per owner: exit code, image captures, captured bytes, files opened, the encoder-fallback rows and the tail of its
  output.
- Per image: size, `equal` (whole rebuilt image == original), SHA-1 of both, bytes per source, unequal bytes per
  source, `rebuilt`, `verbatim`, `generated`, `excepted`, `equal_without_exceptions`.
- Totals.
- Rebuilt images: `out/<game>/<name>.bif.bin` (lab only).
