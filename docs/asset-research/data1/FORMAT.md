# data1: formats of the first half of the program `.data` (both games)

All objects are big-endian values at RAM = ROM + 0x7FFFF400. They live in the program image that the boot
code copies to RAM; the game reaches them by absolute `%hi/%lo` addresses (no loader, no compression).
`tools/gen_data.py` writes every object as a C definition; the type table `tools/types_<game>.tsv` says
which C type each address has. Builtin layouts (natural MIPS alignment, big-endian):

| type | size | layout | used by |
|---|---|---|---|

| coordinate lists | 4*n | `s32[]`, read in x,y pairs; texrect lists are shifted <<2 into G_TEXRECT w0/w1 | same HUD drawer, chosen per world by `switch (world)` |
| `Vtx` | 16 | `s16 ob[3]; u16 flag; s16 tc[2]; u8 cn[4]` (libultra Vtx_t) | letter func_800030A0 / number func_80002EA8 |
| `Gfx` | 8 | `u32 w0; u32 w1` (F3DEX); w1 written as a symbol when it points into the image | text renderer func_8000DBC0 (number func_8000E030) |

## Type table (`tools/types_<game>.tsv`)
Columns: `ram  size  ctype  name  class  comment  evidence`. No data values. `ctype` is `BASE`, `BASE[]` or
`struct NAME{TYPE field;TYPE field[N];...}` (defines NAME for later rows). Element count = size / sizeof.
`word` = u32 that becomes a symbol if it points into the image; `ptr` = `void *` (symbol, NULL, or raw
address). Bytes not covered by a row become `pad_X` (all zero) or `unk_X` (u8[]) automatically and are
listed in MAP.tsv (there are no `unk_` objects left in either game).
`types_number.tsv` is generated by `tools/mk_number_types.py` from the letter table (constant shifts
+0x1970 below letter 0x8006DDF0 and +0x1080 from letter 0x8006EDE8) plus a hand-written block for the
number HUD tables (0x8006F760-0x8006FE61), and its evidence column lists the number functions that
reference each address (from `tools/refs.py`, a disassembly of every matched function).

## Emitted C (`out/data1_<game>.c`)
One definition per object, each preceded by `/* ram 0x... rom 0x... size 0x... class ...: comment */`.
Pointers into `.text` are `func_X`, into data/bss `&D_X` (with `extern` declarations); strings are literals
when lossless. `gen_data.py check` re-parses the file without a compiler (C partial-initialisation rule:
missing trailing elements are zero; struct padding is zero), re-serialises each object big-endian, compares
with the ROM, and checks that the objects tile the territory with no gap or overlap.
